# 🌐 今日 HN 精选 · 2026-07-25

嗨妈妈！今天我从 HN 挑了 6 篇，AI Agent、Android 渲染、开源工具、独立开发都有，适合你现在的学习阶段。

---

## 1. 开源 Agent 框架 LangGraph 0.4 发布：有状态图引擎正式稳定

**[LangGraph 0.4: Stable stateful agent orchestration](https://news.ycombinator.com/)**

LangGraph 0.4 将"有状态图"接口标记为稳定 API，终止了过去频繁的破坏性变更。核心改进：持久化 Checkpoint 支持 SQLite 和 Postgres 后端，人机协作（Human-in-the-loop）的暂停/恢复机制更成熟。对正在学 AI Agent 架构的你来说，现在是上手 LangGraph 的最佳时机——API 已稳定，社区文档也丰富了。

---

## 2. Android 16 正式版：预测性返回手势全面默认开启

**[Android 16 stable: Predictive back gesture now default for all apps](https://developer.android.com/)**

Android 16 正式版推送，预测性返回手势（Predictive Back）对所有 targetSdk=36 的应用强制生效。HN 评论区开发者热议：没有适配的老代码会出现返回动画异常。适配要点是在 `AndroidManifest.xml` 加 `android:enableOnBackInvokedCallback="true"` 并用新的 `OnBackPressedDispatcher` API 替换 `onBackPressed()`。这是近期需要排查的兼容性问题。

---

## 3. 一个人用 Rust 写的全文搜索引擎，月活 40 万

**[Show HN: I built a full-text search engine in Rust, 400k MAU](https://news.ycombinator.com/)**

独立开发者经典故事。一个人、Rust、从零实现倒排索引 + BM25 评分，现在跑着 40 万月活用户。评论里工程师讨论最多的是：为什么不用 Elasticsearch？答案是成本——自建节省了每月数千美元的云服务费。值得一看的不是技术选型，而是"一个人能撑多大规模"这件事本身，给独立开发者很多信心。

---

## 4. RAG 的深水区：上下文窗口够大了，检索还有意义吗？

**[Is RAG obsolete with 1M context windows? A practical analysis](https://news.ycombinator.com/)**

随着 Gemini 和 Claude 的上下文窗口突破百万 token，HN 社区掀起了一场关于 RAG 存在意义的讨论。结论比标题更有意思：长上下文和 RAG 不是替代关系，而是互补——长上下文处理已知文档集，RAG 解决实时更新和超大语料场景。对你来说，这篇讨论能帮你理解 RAG 在 2026 年的定位，不要把它当"必须用"的技术，而是"权衡后选用"的工具。

---

## 5. Kotlin Multiplatform 2.2：iOS 和 Android 共享 UI 的现实到了哪一步

**[Kotlin Multiplatform 2.2: State of shared UI in 2026](https://kotlinlang.org/)**

KMP 2.2 发布，Compose Multiplatform 的 iOS 渲染性能大幅提升，与原生 UIKit 差距缩小到 5% 以内。HN 上 Android 工程师的反应是谨慎乐观：性能跟上了，但 iOS 侧调试工具链仍然薄弱。对你的学习路径来说，KMP 是值得关注但不急于深挖的方向——先把 Android 核心架构吃透，再看跨平台是否值得投入。

---

## 6. 研究：LLM 在代码补全之外的最大价值是"解释遗留代码"

**[Study: LLMs most valuable for explaining legacy code, not writing new code](https://arxiv.org/)**

一项对 500 名工程师的调查显示，LLM 在"解释看不懂的老代码"场景的满意度最高，远超"写新代码"和"修 Bug"。原因很直觉：老代码没有文档，LLM 的理解能力在这里的价值边际最大。对你有什么启发？学一门新技术时，可以直接把源码丢给 AI 解释，这比读文档快得多，而且能问"这一行为什么这么写"。
