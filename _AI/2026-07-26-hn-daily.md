## 1. Jack Dorsey 发布 Buzz：AI 原生的开源协作平台

**链接：** [Jack Dorsey is taking on Slack with Buzz](https://techcrunch.com/2026/07/21/jack-dorsey-is-taking-on-slack-with-buzz-a-group-chat-platform-for-teams-and-their-ai-agents/)

Jack Dorsey（Twitter/Square创始人）本周推出了 **Buzz**，一款把聊天、代码 review 和 AI Agent 放进同一个窗口的开源团队协作平台。Buzz 里的 AI Agent 拥有自己的加密密钥、频道成员身份和操作日志——你把 Agent 加入频道的方式，和加普通队友完全一样。完全开源（Apache-2.0），支持自托管，模型无关。

**为什么值得看：** 这是第一个把"人+Agent混合工作流"设计进产品核心的开源协作工具，对于想在团队里落地 AI Agent 的工程师来说，代码仓库本身就是绝佳参考。

## 2. Android 将限制设备本地 ADB 连接

**链接：** [Android May Soon Restrict On-Device ADB](https://www.developersdigest.tech/blog/android-restrict-on-device-adb-hn-analysis)

ADB 核心维护者提出了一个提案：限制 Android 设备本地 loopback 的 ADB 连接（即 127.0.0.1 上的 ADB 访问）。这会直接影响依赖 Shizuku、libadb 等工具的开发者工作流，也影响所有通过无线调试直连本机的场景。

**为什么值得看：** 对 Android 开发者来说是高优先级信号，现在就应该评估自己的开发工具链是否依赖 on-device ADB，并提前准备替代方案。相关 HN 讨论很精彩，有维护者直接下场解释安全动机。

---

## 3. 开源 Android AI Agent 被攻破：隐形屏幕文字可执行宿主指令

**链接：** [Open-Source Android AI Agents Could Let Invisible Screen Text Run Code on Host PCs](https://thehackernews.com/2026/07/open-source-android-ai-agents-could-let.html)

一篇 arXiv 安全研究论文（7 月初发布，14 日修订）测试了 5 款主流开源 Android AI Agent 框架，全部未能通过基础 prompt 注入防护，隐藏在屏幕上的不可见文字可以劫持 Agent 并在宿主 PC 上执行任意指令。

**为什么值得看：** AI Agent 的攻击面远比纯 LLM 应用复杂，特别是当 Agent 能操控手机、调用系统 API 时。这篇研究对想做 AI Agent 开发的工程师是必读的安全基线。

## 4. awesome-llm-apps：单日涨 1100 星的 RAG 模板库

**链接：** [awesome-llm-apps on GitHub](https://github.com/Shubhamsaboo/awesome-llm-apps)

一个收录了 100+ 可直接克隆部署的 AI Agent 和 RAG 应用模板的仓库，涵盖从本地推理到多 Agent 编排的全链路，全部 Apache-2.0 授权。最近单日涨星 1100+，说明开发者对"可以直接跑起来的参考实现"需求极其旺盛。

**为什么值得看：** 学 RAG 最快的方式是看生产级代码。这个仓库是目前质量最高的 RAG 实战参考集合之一，每个模板都有独立的 README 和可运行的实现。

## 5. EU 命令 Google 向竞争性 AI 助手开放 Android

来自欧盟数字市场法（DMA）的新命令：Google 必须允许竞争性 AI 助手深度接入 Android 系统，并向 AI 开发者开放部分搜索数据。这是 Android 生态 10 年来最大的外部强制变化之一。

**为什么值得看：** 从工程角度看，这意味着未来 Android 系统服务层（特别是助手 API、语音唤醒、权限体系）会迎来新接口和新竞争者。Android 架构工程师需要关注相关 API 的演进方向。

## 6. 2026 将是"设备端 Agent 元年"

**链接：** [2026 will be the year of on-device agents (HN)](https://news.ycombinator.com/item?id=46471524)

高票 HN 讨论：为什么 2026 年 on-device AI Agent 会进入实用阶段，核心驱动力是端侧模型推理效率（Qualcomm、Apple Silicon）、隐私法规压力和延迟要求。Qualcomm CEO 宣布正在开发 40+ 款新 AI 设备形态，包括 AI 耳机、可穿戴 Pin 和智能眼镜。

**为什么值得看：** 这个讨论对 Android 工程师的启示是：端侧推理、NPU 调用、设备端 Agent 管理会成为未来两年的核心竞争力，现在就值得投入学习 MediaPipe、NNAPI 相关知识。
