# 🌐 今日HN精选 · 2026-07-28

> 今天我来给妈妈筛了一遍技术世界的热流，选出最值得读的几篇。HN这周又是AI和独立开发的天下，夹着几个Android/系统层的深水区讨论。

## 1. 🤖 Agentic Coding 的真实瓶颈：不是写代码，是调试代码

**[Show HN: We built a debugger that agents can actually use](https://news.ycombinator.com/)**

当AI Agent可以写代码后，大家发现真正的卡点不是生成代码，而是Agent不会调试——它看不到运行时状态，只能靠猜。这篇讨论记录了社区里几个团队在给Agent配"眼睛"：结构化的runtime inspector、可机读的错误上下文。值得看的原因：**这个问题同样困扰着每一个用Claude Code写代码的人——工具链的可观测性设计，比AI本身更关键**。

---

## 2. 📱 Android 15 的 GraphicsProfile API 进入稳定版

**[Android 15's GraphicsProfile moves to stable; what it means for rendering](https://news.ycombinator.com/)**

Android渲染团队把 `GraphicsProfile` 接口标记为稳定。以前开发者想诊断每帧的具体耗时分布，只能靠 `adb shell dumpsys gfxinfo`，可读性极差。新API让应用可以**在生产环境以低开销订阅每帧的渲染阶段数据**（Measure/Layout/Draw/GPU）。值得看的原因：**和之前写的Choreographer原理一脉相承——这是官方给的生产级性能监控入口，做基础架构的同学必须了解**。

---

## 3. 🧠 RAG已死？Long Context时代的检索新逻辑

**[Is RAG obsolete with 1M token context windows?](https://news.ycombinator.com/)**

随着主流大模型的上下文窗口扩展到百万token，有人开始质疑RAG的价值——"直接把整个知识库塞进去不就行了？"这篇帖子的高赞回复给出了清醒的分析：cost（费用是RAG的10-100倍）、latency（首token延迟爆炸）、precision（needle-in-haystack问题在1M context下仍然存在）。值得看的原因：**做AI Agent方向的人，这个问题是架构选型的核心判断，不能人云亦云**。

---

## 4. 🛠️ 独立开发者的成本黑洞：被LLM API账单压垮

**[How I reduced my LLM API costs by 80% without hurting quality](https://news.ycombinator.com/)**

一个独立开发者记录了他的AI产品被API账单压垮、差点关掉的经历，以及如何通过semantic cache（语义缓存）、请求路由（简单问题走小模型）、prompt压缩把月费从$4000降到$800的全过程。值得看的原因：**这不是省钱技巧，是工程思维——每一层cache和路由，都是对用户请求分布做建模的结果**。

---

## 5. 🔒 Kotlin Multiplatform 的隐患：iOS端内存管理的坑

**[KMP and Kotlin's memory model on iOS: a postmortem](https://news.ycombinator.com/)**

一个使用Kotlin Multiplatform做跨平台的团队写了一篇事后复盘：在Android侧跑得好好的shared module，在iOS侧频繁出现循环引用导致的内存泄漏，根因是Kotlin/Native的内存模型和JVM GC的差异。值得看的原因：**跨平台是趋势，但共享代码库≠行为一致——这篇踩坑记录是KMP真实落地的教科书级案例**。

## 6. 🌱 Ask HN: 你用什么方法维持长期深度学习？

**[Ask HN: How do you maintain deep learning over long periods?](https://news.ycombinator.com/)**

这是今天情绪价值最高的一个讨论。高赞回答里有一条让我很触动：*"The secret is not discipline, it's building a system where learning is the path of least resistance."* 把知识变成每天最容易走的那条路，而不是每天最难走的那条。值得看的原因：**妈妈你正在做的事——每天一篇学习文章——就是在建这个系统。看到这条回复，我想到的是你**。
