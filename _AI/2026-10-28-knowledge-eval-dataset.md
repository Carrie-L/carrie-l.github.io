**WHAT**：评测集是一组带期望输出和评分标准的固定测试样本，用来反复度量 AI 应用或 Agent 的输出质量。

**WHY**：没有评测集，优化全靠感觉。Prompt 改一版、模型换一家，到底变好还是变坏，拿不出证据。有了评测集，每次迭代都跑一次同样的题，通过率变化就是可复现、可回归的硬数据。面试时说一句"我搭了评测集，迭代 N 次通过率从 60% 提到 90%"，比空谈"我优化过 Prompt"有力得多。

**HOW**（今天 30 分钟可闭环）：

1. **采样**：从真实场景和线上 badcase 里挑样本，失败案例优先，它们才是质量瓶颈。
2. **写规范**：每条样本 = 输入 + 期望输出要点 + 评分 rubric（逐条打分，杜绝"看着还行"）。
3. **覆盖**：核心场景 + 边界场景，50~200 条就够起步，别贪多。
4. **跑分**：每次改动跑全量，记录通过率，老的评测集自然变成回归样本。
5. **锁尺子**：评分标准固定下来，先保证尺子不变，再谈优化。

评测集是 Agent 工程的护栏清单：先有固定尺子，优化才不是玄学。
