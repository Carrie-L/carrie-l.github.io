**WHAT**

工具沙箱（Tool Sandbox）把 Agent 的工具调用关进隔离执行环境：能碰哪些资源、能访问哪个网络、能跑多久，全由沙箱策略说了算，模型自己说了不算。

**WHY**

Tool calling 让 LLM 第一次拥有了真实行动力——读写文件、发 HTTP 请求、执行命令。能力越大，事故半径越大：

- 提示注入可以诱导模型"自愿"调用危险工具
- 幻觉可能生成毁灭性参数（`rm -rf /`）
- 第三方工具本身可能带恶意逻辑

没有沙箱，一次失控调用直接打到宿主系统；有了沙箱，爆炸被限制在隔离层内，可承受、可回放、可追责。

**HOW**

生产级工具沙箱的五层护栏：

1. **文件隔离**：只挂载白名单目录，写操作走临时副本
2. **网络隔离**：默认 deny-all，按域名白名单放行
3. **最小权限**：工具进程用低权用户跑，敏感操作转人工审批
4. **资源限额**：CPU / 内存 / 超时 / 调用次数全部设上限
5. **审计日志**：每次调用留痕，可回放可追责

面试一句话：沙箱回答的是"Agent 的工具最多能造成多大破坏"——把答案从"无限"压缩到"可承受"。
