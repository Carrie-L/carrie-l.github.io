## 🔍 逐词基础解析

### 1. 契約（けいやく）🔴 adaptive-revisit

- **词性**：名词
- **意思**：合同、契约
- **常见搭配**：契約を結ぶ（签订合同）、契約書（合同书）
- **例句**：会社と契約を結びました。
- **中文**：和公司签了合同。
- **CC 小提醒**：契 = 契约的契，约 = 约定的约。签合同 = 結ぶ（むすぶ，系、结），想象把双方"系"在一起～

### 2. 誤解（ごかい）🔴 adaptive-revisit

- **词性**：名词・する动词
- **意思**：误解
- **常见搭配**：誤解する（误解）、誤解を招く（引起误解）
- **例句**：彼の言葉を誤解しました。
- **中文**：我误解了他的话。
- **CC 小提醒**：誤 = 错误，解 = 理解。错误地理解 = 误解！汉字词对妈妈来说应该很友好～

### 3. 活かす（いかす）

- **词性**：他动词
- **意思**：活用、有效利用
- **常见搭配**：経験を活かす（活用经验）、知識を活かす（活用知识）
- **例句**：日本語の勉強を仕事に活かします。
- **中文**：把日语学习活用到工作中。
- **CC 小提醒**：这是今天**唯一的动词**！活かす = 让什么东西"活"起来。别让知识沉睡，把它叫醒！✨

### 4. 社会（しゃかい）

- **词性**：名词
- **意思**：社会
- **常见搭配**：社会人（社会人、上班族）、社会問題（社会问题）
- **例句**：社会で役立つ日本語を勉強します。
- **中文**：学习在社会上实用的日语。
- **CC 小提醒**：社会人 = 进入社会的成年人 = 上班族。妈妈就是社会人呀！🍊

### 5. 主張（しゅちょう）

- **词性**：名词・する动词
- **意思**：主张、断言
- **常见搭配**：意見を主張する（主张意见）、自分の考えを主張する（坚持自己的想法）
- **例句**：彼は自分の意見を主張します。
- **中文**：他坚持自己的意见。
- **CC 小提醒**：主 = 主人，張 = 张开。像主人一样张开自己的立场 = 主张！

### 6. 条件（じょうけん）

- **词性**：名词
- **意思**：条件
- **常见搭配**：条件がいい（条件好）、条件を出す（提出条件）
- **例句**：このアパートの条件がいいです。
- **中文**：这个公寓的条件很好。
- **CC 小提醒**：条 = 条款，件 = 事项。一个个条款和事项 = 条件。

### 7. 情報（じょうほう）

- **词性**：名词
- **意思**：情报、信息
- **常见搭配**：情報を集める（收集信息）、情報を調べる（查信息）
- **例句**：インターネットで情報を調べます。
- **中文**：在网上查信息。
- **CC 小提醒**：情 = 情况，報 = 报告。报告情况 = 情报！妈妈每天都在网上查情报呢～

### 8. 水準（すいじゅん）

- **词性**：名词
- **意思**：水准、水平
- **常见搭配**：高い水準（高水准）、生活水準（生活水平）
- **例句**：日本の生活水準は高いです。
- **中文**：日本的生活水平很高。
- **CC 小提醒**：水 = 水面，準 = 基准。以水面为基准 = 水平线！想象一根线画在水上～

### 9. 制度（せいど）

- **词性**：名词
- **意思**：制度、体制
- **常见搭配**：教育制度（教育制度）、会社の制度（公司制度）
- **例句**：日本の教育制度はおもしろいです。
- **中文**：日本的教育制度很有趣。
- **CC 小提醒**：制 = 制定，度 = 尺度。制定好的尺度 = 大家共同遵守的制度。

### 10. 成果（せいか）

- **词性**：名词
- **意思**：成果、成就
- **常见搭配**：成果を出す（拿出成果）、研究の成果（研究成果）
- **例句**：三ヶ月の勉強の成果が出ました。
- **中文**：三个月学习的成果显现了。
- **CC 小提醒**：成 = 完成，果 = 果实。种下的种子结出了果实 = 成果！妈妈每天都在收获果实哦 🍓

## ⚡ 易混点小提醒

**① 契約（けいやく）vs 条件（じょうけん）**
契約是"合同"那份文件/约定本身，条件是"条款要求"。
→ 契約の条件がいい（合同的条件很好）——两个词可以同时出现！

**② 制度（せいど）vs 社会（しゃかい）**
制度是"规则框架"（比如公司制度、教育制度），社会是"整个大环境"。
→ 社会にはいろいろな制度がある（社会中有各种各样的制度）。

**③ 情報（じょうほう）vs 成果（せいか）**
情報是"输入"（收集来的信息），成果是"输出"（做完后的结果）。
→ 情報を集めて、成果を出す（收集信息，产出成果）。

## 🏕️ 迷你小场景

### 场景 1：公司的一天 💼

田中：「おはよう！今日は新しい**契約**の話があるんだ。」
（早上好！今天有个新合同的事。）

佐藤：「へえ、**条件**はどうなの？」
（诶，条件怎么样？）

田中：「**情報**によると、かなりいいみたい。生活**水準**も上がるしね。」
（根据情报，好像很不错。生活水平也会提高。）

佐藤：「よし、これは**成果**が出そうだ！頑張ろう！」
（好，这个看来能出成果！加油吧！）

**🍓 中文小提示**：这个场景练了 **契約・条件・情報・水準・成果** 5 个词。讲的是公司里两个人讨论一份条件不错的新合同，觉得能做出成果。妈妈可以大声读出来，感受一下职场日语的氛围～

### 场景 2：课堂讨论 🏫

先生：「みなさん、日本の**社会**について話しましょう。」
（大家，我们来谈谈日本的社会吧。）

学生 A：「日本の**制度**は面白いと**主張**します！」
（我主张日本的制度很有趣！）

学生 B：「すみません、それは**誤解**かもしれません。でも、留学の**経験**を将来**活か**したいです。」
（不好意思，那可能是误解。不过我想将来说活用留学的经验。）

先生：「いい意見ですね！」
（很好的意见呢！）

**🍓 中文小提示**：这个场景练了 **社会・制度・主張・誤解・活かす** 5 个词。注意「経験を活かす」这个搭配，是 N2 面试和写作的超高频用法！妈妈也要把每天学的日语活かす到工作和生活中哦～💕
