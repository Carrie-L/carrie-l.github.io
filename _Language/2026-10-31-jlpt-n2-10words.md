## 🔍 逐词基础解析

### 1. 確認（かくにん）🔴 adaptive-revisit

- **词性**：名词・する动词
- **意思**：确认
- **常见搭配**：予約を確認する（确认预约）、答えを確認する（确认答案）、安全確認（安全确认）
- **例句**：かばんの中を確認します。
- **中文**：确认一下包里的东西。
- **CC 小提醒**：确 = 确实，認 = 认可。变成"确实被认可" = 确认！工作中收到消息先確認，是靠谱社会人的基本功～妈妈每天都在做的事，就是它！🍊

### 2. 衣料（いりょう）🔴 adaptive-revisit

- **词性**：名词
- **意思**：衣料、衣服料子
- **常见搭配**：衣料品（衣物类商品）、衣料店（衣料店）
- **例句**：この店の衣料品は安いです。
- **中文**：这家店的衣物很便宜。
- **CC 小提醒**：衣 = 衣服，料 = 材料。做衣服的材料 = 衣料！日常说"衣服"一般用 服（ふく），衣料 更书面一点，常见于商店分类和广告里～

### 3. 住宅（じゅうたく）

- **词性**：名词
- **意思**：住宅、住房
- **常见搭配**：住宅地（住宅区）、住宅ローン（房贷）
- **例句**：住宅の値段が高いです。
- **中文**：住宅的价格很高。
- **CC 小提醒**：住 = 居住，宅 = 房子。住的房子 = 住宅！妈妈想住带阳台、能露营装备收纳的房子吗？🏕️

### 4. 収入（しゅうにゅう）

- **词性**：名词
- **意思**：收入
- **常见搭配**：収入を増やす（增加收入）、収入が少ない（收入少）
- **例句**：収入を増やしたいです。
- **中文**：想增加收入。
- **CC 小提醒**：収 = 收，入 = 进入。收进来的钱 = 收入！它的反义词是 支出（ししゅつ），"收支"一对一起记， forever 不会忘～💰

### 5. 主張（しゅちょう）

- **词性**：名词・する动词
- **意思**：主张、坚持己见
- **常见搭配**：意見を主張する（主张意见）、自分の考えを主張する（坚持自己的想法）
- **例句**：彼は自分の意見を主張します。
- **中文**：他坚持自己的意见。
- **CC 小提醒**：主 = 主人，張 = 张开。像主人一样张开自己的立场 = 主张！它比普通的"说"语气更强，带着"我坚持这么认为"的味道～

### 6. 情報（じょうほう）

- **词性**：名词
- **意思**：信息、情报
- **常见搭配**：情報を集める（收集信息）、情報を調べる（查信息）、最新情報（最新消息）
- **例句**：ネットで情報を調べます。
- **中文**：在网上查信息。
- **CC 小提醒**：情 = 情况，報 = 报告。报告情况 = 情报！N2 阅读里几乎每篇都会出现它，属于"见到就赚了"的送分词～✨

### 7. 通勤（つうきん）

- **词性**：名词・する动词
- **意思**：通勤、上下班
- **常见搭配**：通勤時間（通勤时间）、毎日通勤する（每天通勤）
- **例句**：毎日バスで通勤します。
- **中文**：每天坐公交上班。
- **CC 小提醒**：通 = 往返，勤 = 勤务。家和公司之间往返 = 通勤！学生版本叫 通学（つうがく，上下学），一对一起记～妈妈每天通勤辛苦啦，CC 给你捏捏肩 🍓

### 8. 通知（つうち）

- **词性**：名词
- **意思**：通知
- **常见搭配**：入金通知（到账通知）、合格通知（合格通知）、通知が来る（来通知了）
- **例句**：学校から通知が来ました。
- **中文**：学校来了通知。
- **CC 小提醒**：通 = 传达，知 = 知道。传达给你让你知道 = 通知！它通常是单向的：公司→员工、学校→家长，这个方向感记牢就不会和 通信 搞混～

### 9. 通信（つうしん）

- **词性**：名词
- **意思**：通信、通讯
- **常见搭配**：通信が悪い（信号不好）、通信販売（邮购）、通信教育（函授教育）
- **例句**：山で通信が悪いです。
- **中文**：在山里信号不好。
- **CC 小提醒**：通 = 相通，信 = 信息。信息互相通达 = 通信！手机没信号的时候，就可以抬头说「あ、通信が悪い」——学过的词马上就能用！📶

### 10. 提案（ていあん）

- **词性**：名词・する动词
- **意思**：提案、建议
- **常见搭配**：提案を出す（提出提案）、新しい提案（新的提案）
- **例句**：会議で新しい提案をします。
- **中文**：在会议上提出新提案。
- **CC 小提醒**：提 = 提出，案 = 方案。提出方案 = 提案！妈妈在会议上说出自己的想法时，用的就是它，超级职场感～💼

## ⚡ 易混点小提醒

**① 通知（つうち）vs 通信（つうしん）vs 情報（じょうほう）**

通知是"单方面告知"（公司→你），通信是"双向传递/信号"（手机通信），情報是"信息内容本身"。
→ 通知には新しい情報が書いてある（通知上写着新信息）。三个词一句话全用到！

**② 収入（しゅうにゅう）vs 給料（きゅうりょう）**

収入是"总收入"（工资、副业、理财都算），給料是"工资"（公司发的那一份）。
→ 給料は収入の一部です（工资是收入的一部分）。

**③ 提案（ていあん）vs 主張（しゅちょう）**

提案是"提出新方案"（建设性、面向未来），主張是"坚持己见"（表达立场、语气更强）。
→ 新しい提案を出して、自分の意見も主張する（提出新提案，也坚持自己的意见）。

## 🏕️ 迷你小场景

### 场景 1：公司的一天 💼

田中：「あー、毎日の**通勤**、疲れます。」
（啊～每天的通勤好累呀。）

佐藤：「大変ですね。あ、会社から**通知**が来ましたよ。新しい**提案**の話です。」
（真辛苦呢。啊，公司来通知了，是关于新提案的事。）

田中：「本当ですか。**情報**を**確認**します。」
（真的吗？我确认一下信息。）

佐藤：「はい。会議は三時からです。」
（嗯，会议从三点开始。）

**🍓 中文小提示**：这个场景练了 **通勤・通知・提案・情報・確認** 5 个词。讲的是打工人通勤后的日常一幕：收到通知、确认信息、准备开会。妈妈每天在公司是不是也这样？大声读出来，超有代入感～

### 场景 2：商店街找房子 🏠

李さん：「新しい**住宅**を探しています。**収入**が少ないので、安い家がいいです。」
（我在找新的住宅。因为收入不多，所以想要便宜的房子。）

店員：「このマンションはどうですか。**通信**も速いですよ。」
（这个公寓怎么样？通信也很快哦。）

李さん：「いいですね！近くに**衣料**品の店もありますか。」
（真好！附近有卖衣料的店吗？）

店員：「はい、あの角です。値段も安いです。」
（有的，就在那个拐角，价格也很便宜。）

李さん：「じゃ、「安いが一番」と**主張**します！ここに決めます！」
（那我主张"便宜第一"！就决定是这里了！）

**🍓 中文小提示**：这个场景练了 **住宅・収入・通信・衣料・主張** 5 个词。是一个找房子的生活小剧场，从看房到拍板决定，每个词都在真实的对话里活了过来～妈妈可以假装自己是李さん，把这段演一遍！🏕️
